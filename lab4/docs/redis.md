# Работа с Redis в n8n

## 1. Цель работы

Изучить подключение Redis к n8n и освоить основные операции с ключами: создание, чтение, удаление и проверка существования.

## 2. Запуск Redis

Для запуска Redis был использован Docker. В терминале PowerShell выполнена команда:

```powershell
docker run -d --name redis -p 6379:6379 redis:7
```

После запуска была проверена работа контейнера командой:

```powershell
docker ps
```

В списке запущенных контейнеров был найден Redis, использующий порт `6379`.

## 3. Настройка подключения Redis в n8n

В n8n были созданы credentials для подключения к Redis со следующими параметрами:

- Host: `host.docker.internal`
- Port: `6379`
- Database: `0`
- Password: не указывался, так как Redis был запущен без пароля.

Созданные credentials были выбраны в Redis-узлах обоих workflow.

## 4. Создание и чтение ключа

Для выполнения задания был создан workflow `flow-09-redis.json`.

Workflow состоит из следующих узлов:

1. **Manual Trigger** — запускает workflow вручную.
2. **Redis Set** — создаёт ключ `zimens` и записывает в него значение `Hello from n8n - ИИ-241`.
3. **Redis Get** — читает значение по ключу `zimens`.

После выполнения workflow узел Redis Get вернул ранее сохранённую строку. Это подтвердило успешное создание ключа и чтение его значения из Redis.

## 5. Удаление ключа и проверка существования

Для удаления ключа был создан workflow `flow-10-redis.json`.

Workflow состоит из следующих узлов:

1. **Manual Trigger** — запускает workflow вручную.
2. **Redis Delete** — удаляет ключ `zimens`.
3. **Redis Exists** — проверяет, существует ли ключ `zimens` в Redis.

Перед запуском второго workflow был выполнен первый workflow, чтобы ключ `zimens` существовал.

После выполнения Redis Delete ключ был удалён. Узел Redis Exists выполнил проверку и показал, что ключ больше не существует.

## 6. Результат работы

В ходе выполнения задания были успешно освоены основные операции Redis в n8n:

- создание ключа и сохранение значения;
- чтение сохранённого значения;
- удаление ключа;
- проверка отсутствия ключа.

Работа с Redis позволила изучить взаимодействие n8n с базой данных ключ-значение и применение Redis для хранения и обработки данных в автоматизированных workflow.
