# Лабораторная работа № 5
## Создание чат-бота в Typebot

### 1. Цель работы

Изучить возможности платформы Typebot для создания диалоговых чат-ботов, освоить настройку блоков, переменных, условий и HTTP-запросов, а также научиться изменять оформление, тестировать и публиковать готового бота.

### 2. Выбранный трек

Выбран трек C — Typebot.

В качестве основы использован шаблон Customer Support Bot, предназначенный для автоматизации первичного взаимодействия с пользователями и обработки обращений в службу поддержки.

### 3. Ход выполнения работы

**3.1. Создание и локализация бота**

Создан бот на основе шаблона Customer Support Bot. Тексты сообщений, названия пунктов меню и элементы взаимодействия адаптированы на русский язык.

В исходном сценарии предусмотрены варианты обращения: сообщение об ошибке, предложение по улучшению функциональности и вопрос. Также реализованы переходы к дополнительным этапам диалога и завершению взаимодействия.

Скриншоты:
- `01-initial-template.png` — исходный шаблон.
- `02-template-russificated.png` — русифицированный сценарий.

**3.2. Добавление переменных и новых шагов**

В сценарий добавлены шаги для сбора имени пользователя и описания обнаруженной ошибки.

Для хранения ответов используются переменные `userName` и `issueDescription`. Они позволяют передавать введённые пользователем данные в последующие блоки сценария.

Скриншоты:
- `03-two-new-variables.png` — добавленные переменные и шаги.
- `04-changed-bug-report.png` — изменённый сценарий сообщения об ошибке.

**3.3. Настройка условия**

В сценарий добавлен блок Condition для реализации условной логики диалога. Такой блок позволяет выбирать дальнейший путь выполнения сценария в зависимости от заданного условия.

Скриншот: `05-condition-and-http-request.png`.

**3.4. Настройка HTTP Request**

Добавлен блок HTTP Request с методом POST и адресом `https://httpbin.org/post`. Запрос отправляет данные сценария в формате JSON.

Для проверки использован сервис httpbin.org, который возвращает информацию о полученном запросе. При тестировании получен код ответа HTTP 200, подтверждающий успешное выполнение запроса.

В передаваемых данных присутствуют переменные `userName` и `issueDescription`, а также другие данные сценария.

Данный запрос используется для демонстрации работы HTTP-интеграции. Он не является полноценным хранилищем обращений пользователей.

**3.5. Изменение оформления**

Изменены тема и шрифт бота. Настройки оформления позволяют адаптировать внешний вид диалога и сделать интерфейс более согласованным с выбранным стилем.

Скриншоты:
- `06-initial-theme.png` — первоначальное оформление.
- `07-changed-theme-and-font.png` — изменённая тема и шрифт.

Выполнено тестирование диалога. Проверены переходы между этапами сценария, ввод ответов пользователем и отображение сообщений. Отдельно проверена работа HTTP Request.

### 5. Использованные блоки и освоенные возможности

В ходе работы изучены и использованы следующие возможности Typebot:

- **Text / текстовые сообщения** — отображение информации пользователю.
- **Input / ввод данных** — получение ответов пользователя.
- **Variables / переменные** — сохранение и передача введённых данных.
- **Condition** — организация условных переходов.
- **HTTP Request** — отправка данных внешнему сервису по HTTP.
- **Theme и настройки оформления** — изменение внешнего вида бота.
- **Publish** — публикация сценария для взаимодействия по ссылке.

### 6. Выводы

В ходе лабораторной работы был создан и адаптирован чат-бот для службы поддержки на платформе Typebot. Были освоены локализация готового шаблона, добавление новых шагов, работа с переменными, условная логика и отправка данных внешнему сервису посредством HTTP-запроса.

Также были изменены тема и шрифт интерфейса, проведено тестирование сценария и проверена работа HTTP-интеграции. Полученные навыки позволяют создавать интерактивные диалоги и интегрировать их с внешними сервисами.
